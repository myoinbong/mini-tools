네트워크 및 IP 분류 이해하기

공인 IP, 사설(내부) IP, 그리고 서버와 브라우저의 네트워크 식별 원리

Public IP

🌐 공인 IP (외부 IP)

전 세계 인터넷망에서 유일하게 식별되는 주소로, ISP(통신사)가 모뎀이나 공유기에 부여합니다. 외부 웹사이트나 서버가 사용자를 식별할 때 확인하는 IP입니다.

Private IP

🏠 로컬 사설 IP (내부망)

공유기나 사설 네트워크 내부(예: 192.168.x.x, 10.x.x.x)에서 기기 간 구분을 위해 부여되는 주소입니다. 인터넷 외부로는 직접 노출되지 않습니다.

NAT Architecture

🔄 서버 vs 브라우저 탐지 원리

웹 서버(PHP, Node.js 등)는 공유기의 NAT(주소 변환)를 거쳐 통신하므로 클라이언트의 사설 IP를 직접 알 수 없습니다. 반면 웹 브라우저는 WebRTC P2P 기술을 활용하여 기기 로컬 단에서 사설 IP 조회를 시도할 수 있습니다.

Privacy Shield

🛡️ 브라우저 mDNS 보안 보호

최신 브라우저(Chrome, Safari 등)는 웹사이트가 사용자의 로컬 IP를 수집하여 기기 지문(Fingerprinting)을 생성하는 것을 막기 위해 사설 IP 대신 난수화된 .local mDNS 주소로 마스킹하여 보호합니다.
